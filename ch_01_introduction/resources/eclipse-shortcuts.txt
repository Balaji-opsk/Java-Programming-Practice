Eclipse Shortcuts
~~~~~~~~~~~~~~~~~~~~~
CTRL + ShIFT + L					:	Brrings up a List of shortcut keys 

CTRL + SHIFT + F					:	Automatic Formatting Code
CTRL + I							:	Automatic Indentation
CTRL + F11							:	Execute Program / Run Program
CTRL + /							:	Single Line Comment
SHIFT + ALT + J						:	Multi Line Comment (Comments above class name)
FORWARD SLASH + * + ENTER			:	Multi Line Comment
Type main + CTRL + SPACEBAR + ENTER	:	Main Method
Type syso + CTRL + SPACEBAR + ENTER	:	System.out.println();
Type sys + CTRL + SPACEBAR + ENTER	:	System.err.println();
CTRL + SHIFT + O					:	Organize Imports
CTRL + SPACEBAR						:	Auto Complete Suggestions
CTRL + SHIFT + S					:	To Save Multiple Class Files at once.
CTRL + MINUS -						:	Zoom Out
CTRL + PLUS +						:	Zoom In
CTRL + D							:	Delete current line 
CTRL + SHIFT + R					:	Open resource
ALT + UP OR DOWN ARROW KEYS			:	Move Line up or down
SHIFT + ENTER						:	Create a new line
CTRL + N							:	Create a new resource
CTRL + ALT + DOWN ARROW KEY			:	COPY LINE AND PASTE IN NEW LINE
ALT + D + SELECT CURSOR				:	SELECT MULTIPLE CURSOR
ALT + SHIFT + R						:	REFACTOR RENAME
CTRL + 2, L							:	ASSIGN STATEMENT TO NEW LOCAL VARIABLE
CTRL + W							:	CLOSE CURRENT OPENED TAB
CTRL + SHIFT + /					:	ADD BLOCK COMMENT
CTRL + SHIFT + /					:	REMOVE BLOCK COMMENT
CTRL + M							:	Toggle Project Explorer / Package Explorer / Openend Tab
